# NIT3213 Final Android App

## Project Name:
Fashion Dashboard App

## Description:
This is an Android application developed for the NIT3213 Final Assignment.  
The app allows users to log in, view a list of fashion-related items (Dashboard), and view details of each item.

## Features:
- Login Screen (Username & Student ID)
- Dashboard Screen (List of Items from API)
- Details Screen (Full Details of Selected Item)
- API Integration using Retrofit
- MVVM Architecture
- Dependency Injection with Hilt
- Unit Testing using JUnit & MockK
